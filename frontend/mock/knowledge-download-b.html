⑤ 若定稿,代码里改什么(供实现对照)

  • 后端(knowledge.py 的普通 router,不能挂 /admin 前缀 —— 普通用户没有管理员权限):新增 GET /api/v1/knowledge/download?key=…,登录即可;key 为空或以 / 结尾 → 400;OSS 未接通 → 503(沿用 _dep_503);成功返回 {"url": …}。
  • oss.py:sign_url 加可选文件名参数,签名时带 params={"response-content-disposition": "attachment; filename*=UTF-8''<百分号编码的原名>"}(oss2 2.19.1 的 sign_url 支持 params,已核实)。
  • 为什么必须带 response-content-disposition:HTML 的 download 属性跨域失效,想让浏览器「下载而不是打开」只能靠响应头;顺带保住中文文件名。链接短时效(约 300 秒),点了才签一次,不预签整表。
  • 前端 api.ts:加 downloadFile(key): Promise<string>。
  • useKnowledge.ts:加 downloadingKey 状态与 downloadFile(key)(取到 URL 后建临时 <a> 触发下载,失败抛给调用方)。
  • KnowledgeView.vue:行尾 .kv__act 改为两种角色都渲染(文字「下载」按钮),删除按钮保持 v-if="canWrite"、同样常显;下载中该格换「下载中…」;失败进现有 opError 红条(文案前缀「下载失败:」,详情取 errorText)。
  • 删除 ✕ 改常显(本次一并定):KnowledgeView.vue 的 scoped 里删掉 .kv__del 的 opacity: 0 与 .kv__row:hover .kv__del 浮现规则,以及窄屏 @media 里的 .kv__del { opacity: 1 }(.kv__when 的隐藏保留);保留 muted → 悬停 seal 红。
  • 样式:只在 KnowledgeView.vue 的 scoped 里新增 .kv__dl(height 24px;padding 0 8px;font-size 12px;muted → 悬停 primary + primary-tint),不动全局 css;焦点环走全局。
  • 计量:下载是 OSS 直读,不算模型调用,不进「调用与费用」。
