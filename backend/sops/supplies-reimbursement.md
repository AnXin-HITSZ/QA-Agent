# 耗材与试剂报销流程

## 适用范围
实验室日常实验耗材、化学试剂等低值易耗品的采购报销。

## 所需材料
1. 采购申请单(大额采购需事先审批)
2. 增值税发票(抬头为单位全称,含税号)
3. 采购清单 / 明细(注明品名、规格、数量、单价)
4. 入库单或验收记录

## 办理步骤
1. 采购前在采购平台或线下确认供应商与价格。
2. 到货后核对品名、规格、数量并做验收登记。
3. 登录财务系统,新建「材料费报销单」。
4. 填写明细并关联采购申请单,上传发票与清单。
5. 提交课题负责人审批。
6. 审批通过后将纸质单据送交财务处审核、打款。

## 注意事项
- 危险化学品须走危化品采购与登记流程,不适用本流程。
- 发票为清单开具时,须附销货方开具的销货清单(加盖发票专用章)。
- 单张发票金额较大时,财务可能要求提供采购合同或比价记录。
