# 差旅费报销流程

## 适用范围
因公出差产生的城际交通费、住宿费、市内交通费及差旅补助。

## 所需材料
1. 出差审批单(出差前已审批)
2. 城际交通票据(火车票 / 机票行程单 / 高铁票)
3. 住宿费发票(增值税普通或专用发票,抬头为单位全称)
4. 市内交通票据(出租车票 / 网约车电子发票)

## 办理步骤
1. 登录财务系统,新建「差旅费报销单」。
2. 按行程逐项填写交通费、住宿费、补助,并关联出差审批单。
3. 上传并粘贴对应票据(纸质票据贴于粘贴单)。
4. 提交至课题负责人审批。
5. 审批通过后,将纸质单据送交财务处审核。
6. 财务复核无误后打款至本人工资卡。

## 注意事项
- 住宿费标准按学校差旅管理办法执行,超标部分自理。
- 机票需同时提供行程单与登机牌(或电子登机凭证)。
- 发票抬头、税号须与单位一致,否则无法报销。
