# 记忆系统统一配置（2026-10-12）

本指南替代旧文档中的记忆暂停开关、图子开关、统一抽取和紧凑选择开关矩阵。历史评测产物保持原样；其中旧配置字段是当时的实验记录，不是当前可配置开关。

## 唯一功能开关

```ini
MEMORY_GRAPH_ENABLED=false
```

false：普通长期记忆，图模块不连接Neo4j。true：在普通记忆上开启统一事实/图结构抽取、图写入、后台图同步/清理/对账及图召回。改环境变量后重启程序，不提供前端或请求级运行时开关。

普通记忆的提取、维护决策、回答检索、后台任务、Qdrant对账修复和紧凑证据选择固定启用。Reranker连接、模型和密钥配置完整即使用，失败明确降级。提取固定要求JSON对象，字段与来源仍由Pydantic验证；提供商需支持该结构化输出方式。MySQL未配置时按软依赖处理，记忆管理返回配置缺失，不伪装成没有记忆。不要为了暂停记忆清空共享MYSQL_URL，它也用于认证及计量。

## 必要参数

```ini
# 独立于知识库集合；生产和评测保持隔离
MEMORY_COLLECTION=user_memory
MEMORY_TOP_K=6
MEMORY_CONTEXT_CHARS=2000

# 0停止保存新的完整原始来源，正数表示保留天数
MEMORY_SOURCE_RETENTION_DAYS=0
# 0不补检索，1允许来源回查，2最多一次规划和两条补查询
MEMORY_EVIDENCE_ROUNDS=0
MEMORY_SOURCE_CONTEXT_CHARS=1000
```

来源保留和补检索仍是策略参数，默认均0，因为当前未证明补检索净准确率收益。保留期限0不会立即删除此前存储的来源；尚未过期的来源可在rounds>0时继续读取。完整原始来源与图事实保留的必要摘录不同：统一图抽取的已验证摘录作为事实上下文按记忆生命周期维护，不受完整来源表的TTL替代。

开启来源保存/回查前需0010迁移。不保存来源且不回查时不要求存在该表。普通编辑/删除撤销相关来源，彻底清除覆盖其正文、任务和关联数据；关闭图时外部图清理意图持久化待恢复，不虚报已清理。

继续保留MySQL、Qdrant、Redis、LLM、Embedding和Reranker服务参数；图开启时需Neo4j连接及认证参数。召回/重排候选数、图跳数与节点路径预算、连接超时、任务租约、重试及批量参数仍按.env.example配置。MEMORY_CONTEXT_CHARS是包含标签的参考正文预算，全局参考说明和系统回答规则另计；不从句中间裁切半条事实。

## 从旧.env迁移

删除以下旧字段，它们不再影响运行：

```text
MEMORY_ENABLED
MEMORY_WRITE_ENABLED
MEMORY_SEARCH_ENABLED
MEMORY_MAINTENANCE_ENABLED
MEMORY_WORKER_ENABLED
MEMORY_WORKER_INDEX_REPAIR
MEMORY_LLM_JSON_MODE
MEMORY_GRAPH_WRITE_ENABLED
MEMORY_GRAPH_SEARCH_ENABLED
MEMORY_GRAPH_WORKER_ENABLED
MEMORY_UNIFIED_EXTRACT_ENABLED
MEMORY_SOURCE_STORE_ENABLED
MEMORY_SOURCE_SEARCH_ENABLED
MEMORY_EVIDENCE_SELECTION_ENABLED
RERANK_ENABLED
```

保留MEMORY_GRAPH_ENABLED和服务配置。原来关闭来源保存时，显式把MEMORY_SOURCE_RETENTION_DAYS设为0；仅删除旧SOURCE_STORE开关但保留30天，会按新策略开启保存。原来关闭来源回查时，把MEMORY_EVIDENCE_ROUNDS设为0。原来图总开关开启但图召回子开关关闭时，重启后图召回将开启；生产不再支持这一组合。

本轮没有读取输出或修改真实.env、迁移生产库、清空数据或部署服务。重启之前按本节核对配置。

## 同构建图召回消融

先开启图总开关构建一次完整记忆和图，build complete=true后使用同一run-id：

```bash
cd /d/Projects/QA-Agent
bash eval-memory.sh --action ask --run-id "$EVAL_RUN_ID" --variant graph-off --graph-recall disabled --context-chars 100000
bash eval-memory.sh --action score --run-id "$EVAL_RUN_ID" --variant graph-off
bash eval-memory.sh --action ask --run-id "$EVAL_RUN_ID" --variant graph-on --graph-recall configured --context-chars 100000
bash eval-memory.sh --action score --run-id "$EVAL_RUN_ID" --variant graph-on
bash eval-memory.sh --action compare --run-id "$EVAL_RUN_ID" --variants graph-off,graph-on --axis graph
```

ask/score会调用付费服务；以上是操作示例，本轮未执行。disabled只在该评测命令作用域关闭图召回，不改变环境、不改权威数据、不开写入，也不连接Neo4j召回。configured遵守图总开关，不能把环境中关闭的图强行开启。不要把variant名字当开关；graph-off的名字本身不控制行为。
