# 图记忆召回优化与固定构建验证

本次仅调整检索和评测协议，不改变事实提取、实体消歧、维护、权限或图投影模型。旧 run、答案和评分不覆盖；复用已完成的固定构建，不重新调用提取模型。

## 修改机制

- `graph-recall/3` 使用当前 user/scope 的有效记忆正文计算 BM25 查询相关度，再把证据相关度传播到其关系、事件和参与实体。查询中已匹配的实体名称及常用英文虚词不计入优先级，避免人物名称支配所有关联事实。正文只供此次检索，不进入 Neo4j 投影，不改变投影摘要。
- Neo4j 按同一层的多个节点批量展开；仍按节点、邻居、深度、候选和总时间预算限制。候选先按相关度排序，再截取路径预算，不再找到前几条直接提及记忆就停止遍历。此排序只是候选优先级，不构成事实推理。
- Reranker 返回整个已发送候选集的顺序，最终 top_k 与上下文预算仍由选择层执行。未合法返回的候选继续按融合顺序补尾，并保留诊断。
- 保留原两路 RRF 排名前列的重排候选，在现有文档数和字符硬上限内补入图候选，避免图候选提前挤出已召回的证据。图开启可能发送更多重排文档，最终 top_k 与正文预算不变。诊断保存原池和实际池。
- 图证据选择仅在存在图路径时执行；关闭图召回不再误报图路径预算。收尾版本变化只撤回实际选用的不完整组合，避免未选用路径牵连其他证据。
- 评测回答协议 `eval-answer/5` 将无依据时的固定输出改为 `No information available`，与已有类别 5 评分协议一致。没有扩大拒答评分的字符串规则，也不重算旧结果。总体 F1 的变化可能包括协议对齐收益，应同时查看可回答题与分类别结果。
- 评测提示要求完整覆盖问题需要的项目；裁判协议 `locomo-judge/3` 明确不可回答标记优先，并不向裁判提供这类题可能矛盾的参考答案。此修改只作用于评测，不修改生产回答或提取提示。
- 评测 CLI 在供应商 HTTP 响应明确表示余额不足或额度耗尽时立即非零退出，绕过降级与重试流程，保存安全的 `billing-stop.json`。这不是余额查询接口，不能预测余额；普通限流不视为余额耗尽。仅作用于评测 CLI 的同步 HTTP 调用，不改变生产服务降级行为。停止后的结果可能不完整，不能作为正常完整实验评分。
- 对比工具区分配置一致与运行期间无故障；出现服务失败或回退时 `comparable=false`，结果只供诊断。预算裁剪仍作为诊断，不冒充服务故障。每次比较写入新的 `comparisons/<UTC时间>/`，保留旧比较报告。

## 结论边界

BM25 无法理解所有同义词；名称匹配和现有实体消歧仍有局限。有界遍历可能漏掉路径，图结构也不能恢复提取阶段丢失的事实。仍需按题核验：事实存在、候选进入、重排选择、证据完整、回答使用是否正确。单个样本的改善不能证明泛化；温度 0 也不能保证供应商响应和裁判完全确定。

离线回归、真实 Neo4j 集成与真实付费效果实验分别报告，不相互替代。最终实际结果见同一 run 下的新增实验文件及优化总结。

逐题裁判结果为 5 题改善、0 题退步，但人工检查发现其中两处不能直接归因于图：Q150 两组答案完全相同却获不同判定；Q96 两组均包含参考要求的三项活动，裁判只认可图组。因此最多只能把原始分数视为当前裁判下的观测值。5 对 0 的二项双侧检验约 p=0.0625，且存在裁判误差；不能宣称稳定或显著提升。
